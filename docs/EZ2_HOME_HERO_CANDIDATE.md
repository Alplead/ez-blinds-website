# EZ2 Elementor home hero — unpublished engineering candidate

This is a single hero container only, not an approved homepage or a production-ready Elementor export. The Owner has not approved final page order, media placement, motion, copy, or publication. It must not be imported into any existing WordPress site.

The candidate preserves T2-inspired engineering parameters for an isolated future EZ2 review: four symbolic media slots, 90vh first screen, 5,000 ms slide duration, 1,200 ms fade, Ken Burns zoom-in, and 45% dark overlay. These settings are not proof of tested Elementor Free 4.3.4 behaviour. No customer photographs or private media URLs are in the repository.

Files: design/ez2-home-hero-candidate.json, scripts/ez2_home_candidate_check.py, and scripts/test_ez2_home_candidate_check.py. Regression tests validate schema, motion parameters, symbolic media references, and disposable offline media compilation. They do not run Elementor, install plugins, deploy content, or perform responsive/visual QA.

For a later isolated runtime test, map each slot to an authorised local WordPress Media Library attachment outside this public repository, use the existing private compiler, and require a separately approved isolated EZ2 WordPress environment. Never apply this candidate to production, historical T2, or EZ BNS New Dev. Existing first-party Theme/Core release artifacts remain unchanged.
